Job Drafts

For a shoot that isn't locked in yet -- date confirmed but time/package/who's shooting it may still change before the shoot. Save as Draft creates no folder (neither local nor Dropbox): the draft is stored on the job server (so it opens on any of your computers) and, if a Shoot Time is set, a calendar file is dropped into the Job Root Folder. Click a draft below to reopen it; click Create Job to create the folders and assign the Job ID.

8Save Draft & Create Job

Save as Draft creates no folders -- it saves the draft on the job server and (with a Shoot Time) writes one calendar file into the Job Root Folder, for a shoot that isn't locked in yet. Create Job creates the local + Dropbox folders and assigns the Job ID (finalizing a Draft, or minting a brand-new job) -- or, if a job for this same Shoot Date + Address + Client already has an ID, updates it in place instead.

Sync an Existing Job with Dropbox

For a job you already created (not the one above). Sync to Dropbox uploads local changes to Dropbox; Sync to Local downloads Dropbox changes to local. A file changed on both sides since the last sync is never guessed at -- it's left alone and listed as a conflict for you to resolve by hand. Deletions are mirrored too (removing a file on one side removes it from the other next sync), unless the other side also changed since the last sync, which is likewise reported as a conflict rather than silently deleted.
